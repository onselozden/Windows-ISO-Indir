# Windows ISO İndir

Güncel **Türkçe Windows 10 / 11** ISO dosyasını, [UUP dump](https://uupdump.net) üzerinden doğrudan Microsoft sunucularından indirip oluşturan küçük bir Windows uygulaması.

- Windows 11 (en güncel sürüm, x64 / ARM64) ve Windows 10 22H2 (x64 / x86)
- Pro, Home veya Pro + Home
- İsteğe bağlı olarak son güncellemeleri ekler
- Yönetici olarak çalışır; en az 20 GB boş alan önerilir

Derleme: `derle.bat` (Windows'taki .NET Framework 4.x csc.exe ile).

Hazırlayan: Önsel
